## 🔧 Useful Settings

### Automatic Server Selection
The default setting is perfect for most users. The app continuously checks server speeds and automatically connects you to the fastest one.

### Connection Protocols
For advanced users, you can change the connection type:

1. Go to **Settings** (gear icon in the top menu).
2. Click on **"Connection"**.
3. Choose **"NordLynx"** for fastest speeds or **"OpenVPN"** for maximum compatibility.
4. Click **"Apply"** to save your choice.

### Kill Switch (Emergency Stop)
This safety feature automatically blocks all internet traffic if your VPN connection drops. This ensures your data is never exposed accidentally.

1. Open **Settings**.
2. Click **"Privacy"**.
3. Toggle the **"Kill Switch"** option to **ON**.
